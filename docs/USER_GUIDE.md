## Getting Started

### First Time Login

1. **Account Creation**
   - Contact your HR administrator to create your employee profile
   - Use the "Sign Up" option with your Employee ID
   - Create a username and secure password
   - Your account will be linked to your employee profile

2. **Initial Setup**
   - Complete your profile information
   - Review your leave balances
   - Familiarize yourself with company leave policies

### Navigation

The application uses a sidebar navigation with the following sections:
- **Dashboard**: Overview of your leave status
- **Profile**: Personal information and settings
- **Leaves**: Submit and manage leave requests
- **Calendar**: View leaves and holidays
- **Additional sections** based on your role

## Managing Leave Requests

### Submitting a Leave Request

1. **Navigate to Leaves Section**
   - Click "Leaves" in the sidebar
   - Click "New Leave Request" button

2. **Fill Out Request Form**
   - **Leave Type**: Select from available policies (Annual, Sick, etc.)
   - **Start Date**: First day of leave
   - **End Date**: Last day of leave
   - **Reason**: Optional description

3. **Review and Submit**
   - Check duration calculation
   - Review leave balance impact
   - Verify holiday overlaps
   - Submit for approval

### Leave Request Workflow

**Standard Workflow**:
1. **Employee** submits request
2. **Manager** reviews and approves/rejects
3. **HR** provides final approval
4. **Employee** receives notification of decision

**Special Cases**:
- **HR Staff**: Requests auto-approved
- **Manager/Admin**: Requests go directly to HR
- **No Manager**: Requests go directly to HR

### Managing Your Requests

**View Requests**:
- See all your submitted requests
- Filter by status (Pending, Approved, Rejected)
- Search by leave type or date

**Edit Requests**:
- Only pending requests can be edited
- Click the edit icon on any pending request
- Make changes and resubmit

**Cancel Requests**:
- Delete pending requests if no longer needed
- Approved requests cannot be cancelled through the system

### Leave Balances

**Understanding Your Balance**:
- **Available**: Days you can currently use
- **Used**: Days already taken this year
- **Pending**: Days in submitted but not approved requests
- **Entitlement**: Total days allocated per year

**Balance Calculations**:
```
Available = Opening + Annual Entitlement - Used - Pending
```

## Troubleshooting

### Common Issues

**Cannot Submit Leave Request**:
- Check if you have sufficient balance
- Verify dates are in correct format
- Ensure leave type is available to you
- Contact HR if policy restrictions apply

**Request Stuck in Pending**:
- Check with your manager for approval
- Verify manager is assigned in system
- Contact HR if manager is unavailable
- Check for system notifications

**Balance Discrepancies**:
- Review leave history for accuracy
- Check for pending requests
- Contact HR for balance adjustments
- Verify policy entitlements

**Login Problems**:
- Verify username and password
- Check if account is active
- Contact admin for password reset
- Ensure employee profile exists
